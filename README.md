# ❤️ Liquid Love Heart • Aesthetic Liquid Glass Web Experience

A web application with an **Aesthetic Liquid Glass** user interface, centered around an interactive portal that unveils a huge, multilingual typography animated heart.

This application is built based on your uploaded Python script (`heart_animation.py`), reproducing its parametric mathematics, multilingual phrases, fluid entrance physics, and shimmering sparkles directly in high-performance HTML5 Canvas & Web Audio API, while also providing a built-in launcher and viewer for the original Python script.

---

## ✨ Features

- **Liquid Glass Aesthetic UI (Glassmorphism 2.0)**:
  - Deep obsidian dark velvet theme (`#060208`).
  - Frosted glass cards with specular highlights, chromatic refraction, multi-layered inner bevels, and radiant crimson light orbs.
  - One majestic **Liquid Glass Button** in the center of the landing view with organic liquid border glow, pulse rings, and hover ripples.
- **Hero Page Huge Heart Animation**:
  - Direct mathematical port of your uploaded Python Turtle/Tkinter script.
  - Parametric heart equation: 
    $$x = 16 \sin^3(a)$$
    $$y = 13 \cos(a) - 5 \cos(2a) - 2 \cos(3a) - \cos(4a)$$
  - Multilingual love phrases in 20 languages ("I love you", "Te amo", "Je t'aime", "愛してる", "사랑해", "我爱你", etc.).
  - Easing entrance: cubic ease-out ($1 - (1 - u)^3$), $dx$ drift, vertical lift offset, and drop shadow halos.
  - Dynamic color transitions: deep wine $\to$ crimson $\to$ blood red, flashing up to soft pastel pink-white (`#ffd4d4`).
  - Continuous post-placement shimmer effect with gentle sparkle pulses.
- **Interactive Love Controls**:
  - **Magnetic Cursor Interaction**: moving the cursor near words gently displaces them with a radiant light aura.
  - **Click Burst**: clicking anywhere on the heart canvas scatters radiant stardust and floating embers.
  - **Web Audio API**: celestial harmonic chimes synced with falling phrases, warm sub-bass heartbeat pulse, and ambient toggle.
  - **Liquid Glass Control Dock**: Replay, Speed controls (0.5x, 1x, 2x), Floating Petals toggle, Shimmer toggle, and Fullscreen.
- **Uploaded Python File Integration**:
  - Preserved verbatim as `heart_animation.py` in the workspace.
  - Integrated Liquid Glass modal to inspect, copy, or download the original code.
  - **"Launch .py Window"** button: launches the native Python Turtle GUI window on your Windows desktop.

## 🚀 How to Run

### Option 1: Instant Browser Launch (Zero Dependencies)
You can directly double-click or open `index.html` in any modern web browser (Edge, Chrome, Firefox, Brave):
```
C:\Users\amirc\.gemini\antigravity\scratch\liquid-love-heart\index.html
```

### Option 2: Run with Local Python Server (Recommended for Native GUI Launcher)
Double-click `run.bat` or run in terminal:
```powershell
cd C:\Users\amirc\.gemini\antigravity\scratch\liquid-love-heart
py server.py
```
This serves the website at `http://localhost:8080` and enables the **"Launch .py Window"** button on the website.

### Option 3: Run the Uploaded Python Script Directly
Double-click `run_native_turtle.bat` or run:
```powershell
cd C:\Users\amirc\.gemini\antigravity\scratch\liquid-love-heart
py heart_animation.py
```
